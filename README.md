# HR Analytics Dashboard

##  Live Demo
The dashboard is live at: [HR Analytics Dashboard](https://hr-analytics-dashboard-srs.netlify.app/)

##  Overview
The **HR Analytics Dashboard** is a web-based visualization tool that provides key insights into HR data using an interactive Power BI dashboard. It enables users to explore workforce trends, employee performance, and HR metrics across different departments.

##  Features
-  **Dynamic Dashboard Navigation**: Switch between different sections (Main, HR, R&D, Sales).
-  **Embedded Power BI Dashboard**: Displays interactive data insights.
-  **Smooth UI Enhancements**: Animated popups, modern styling, and responsive design.
-  **Dark Theme**: Aesthetic and easy on the eyes.

##  Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Dashboard Creation**: Power BI
- **Hosting**: Netlify

##  Notice
 The dashboard is a **static preview**, meaning some interactive features like filtering and real-time updates **may not be available**.
